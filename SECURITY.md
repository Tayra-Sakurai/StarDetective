# Security Policy

Please read this security policy before you commit or use this app.

## Supported Security Updates

The security updates are only supported for the latest major version.

## Reporting vulnerability

Please report vulnerability privately by publishing a report on vulnerability reporting.

## For Security Testers

Please tell us that you will conduct a security test **before** you start the test. If we received no message, we may assume that your test is an attack to our repository.
